# Privacy Policy — SmartFill

_Last updated: 2026-10-11_

SmartFill is a job application autofill extension. This policy explains what data it
handles and where that data goes.

## What SmartFill stores

SmartFill stores the profile information **you** enter in its settings page — such as your
name, email address, phone number, postal address, links, work authorisation, employment
history, education, optional demographic answers and long-form answers.

This data is stored **locally in your browser** using `chrome.storage.local`.

## What SmartFill transmits

**Nothing.** SmartFill contains no analytics, no telemetry and no server component. It does
not send your data to the developer or to any third party, and it makes no network requests.

## What SmartFill reads from pages

When — and only when — you explicitly trigger a fill (by clicking the extension, pressing
the keyboard shortcut, or using the context menu), SmartFill reads the form fields on the
active tab in order to determine what each field is for and fill it.

- SmartFill does not run automatically on pages you did not ask it to act on.
- SmartFill does not read, collect or store the content of pages you visit.
- SmartFill never fills file inputs, captchas, or sensitive identifiers such as social
  security numbers or payment card numbers.

## Data you delete

Deleting a profile, or using **Delete all data** in settings, permanently removes the stored
information from your browser. Uninstalling the extension also removes all stored data.

## Contact

Questions about this policy can be raised via the project's GitHub issue tracker.
